# Changelog

## Unreleased

### Added

- Mojo lexer, parser, PSI, file type, and file icon.
- Syntax and semantic highlighting with configurable colors.
- Highlighting for declarations, calls, parameters, fields, decorators, and built-in types.
- Editor support for line comments, braces, and single, double, and triple quotes.
- Stub indexes for named declarations, functions, structures, traits, and types.
- Module indexing and import-path navigation for source modules and packages.
- Tests for lexing, parsing, highlighting, and editor actions.
